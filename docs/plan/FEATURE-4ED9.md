# FEATURE-4ED9 — Windows MSI build script

**Status:** IN PROGRESS
**Type:** FEATURE
**Branch:** one per phase, see below
**Run:** feature/2026-11-03-icons-msi-release

## Objective

One command builds the Windows installer, exactly as Enigma.GitClient does (its FEATURE-EAB7):
`packaging/windows/buildmsi.ps1` (and a `buildmsi.bat` twin) cleans the repository, publishes the release, and
builds `artifacts/Enigma.HardCopy.X.Y.Z.msi` with Enigma.Msi. The repository carries a copy of Enigma.Msi's
worker CLI. The product is named **Enigma HardCopy**, has its own upgrade code, and takes its version from
`Directory.Build.props`.

## Context & constraints

- **The reference** is Enigma.GitClient at `a58d8fe`: `packaging/windows/Enigma.Msi.Worker/` (20 binaries and a
  README), `packaging/windows/buildmsi.ps1`, `buildmsi.bat`, the `.gitignore` rule for `.wixsharp/`, its README's
  *Windows installer* section, and `WindowsInstallerIdentityTests`.
- **No HardCopy MSI exists yet.** No "Enigma HardCopy" product is registered in the uninstall keys of this
  machine (checked read-only while planning), and the repository never built one. So there is no upgrade code to
  keep; a new one is generated once, here, and never changes.
- **Enigma.Msi** (`C:\Dev\EnigmaLibs\Enigma.Msi`, tag `1.7.0` = `a7a1bfb`, clean tree): its built
  `src/Enigma.Msi.Worker/bin/Release/net472/` is byte-identical to GitClient's vendored copy (checked with `cmp`).
  `Enigma.Msi.Worker.exe build <file.msipkg.json>`; exit codes `0` built, `1` invalid package or failed build,
  `2` bad invocation. Needs the WiX CLI (7.0.0 installed here, EULA accepted).
- **Publish** (FEATURE-92E2): `packaging/windows/publish.ps1` runs `dotnet publish src\Enigma.HardCopy.Desktop
  -c Release -r win-x64 -p:PublishReadyToRun=true` → `src\Enigma.HardCopy.Desktop\bin\Release\net10.0\win-x64\publish\`,
  with `app.ico` beside `Enigma.HardCopy.Desktop.exe` (FEATURE-C5C6). The csproj already drops the native PDBs
  from every publish (`TrimNativeSymbolsFromPublish`), so the MSI will not carry GitClient's 100 MB of them.
- **Names:** `ProductInformation.DisplayName` = `Strings.AboutProductName` = "Enigma HardCopy"; the assembly is
  `Enigma.HardCopy.Desktop`; `<Authors>` is "Josué Clément".
- `.gitignore` ignores `artifacts/`, `*.pdb`, `[Bb]in/`, `x64/`, `[Rr]elease/`; the vendored folder matches none.
  `.gitattributes` marks `*.dll` / `*.exe` binary and `*.bat` CRLF.
- Windows PowerShell 5.1 reads a BOM-less script as ANSI, and `.editorconfig` says UTF-8 without BOM, so the
  `.ps1` stays ASCII.
- **Tests** for packaging files live in `Enigma.HardCopy.Desktop.UnitTests` (`PublishScriptsTests`,
  `LinuxPackagingTests`), reading the repository through `RepositoryRoot`. The whole suite runs on this machine.
- **The run may not run `git clean`** in this repository; the script is verified end to end in a scratch clone.
